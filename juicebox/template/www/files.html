How to use
  • Open on a .hic file starts Juicebox with that contact map in a new tab.
  • To add tracks or 2D annotations (bigWig, BED, BEDPE, ...) or a second map, click Copy URL here, then in Juicebox use Load Tracks / Load Contact Map › URL and paste it.
  • Files are shared read-only, and only while this OnDemand session is running. Saved Juicebox sessions and share links that point here stop working when it ends.
  • Anyone you send one of these links to can read this folder until the session ends.
